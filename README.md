# 💸 CLI da Cotação do Dólar

Este programa é um gerenciador de câmbio entre Real (BRL) e Dólar (USD). Os registros são feitos no arquivo `registros.csv`, de tabela única. No programa o usuário pode fazer o câmbio de USD para BRL ou vice versa, escolhendo um valor na moeda original e podendo, ou não, confirmar a transação. Também é possível visualizar todos os câmbios já registrados em formato de tabela.

## 📚 Conceitos praticados

- **Programação Orientada à Objetos:** Métodos escritos em uma classe à parte do `main`. Construtores, métodos e atributos estáticos.
- **venv:** Primeiros contatos com ambientes virtuais em Python.
- **Requests Module:** Consumo de APIs externas. Neste caso, da AwesomeAPI.

## 🚀 Como executar

1. Certifique-se de ter o Python instalado.
2. Clone este repositório:
   ```bash
   git clone https://github.com/Davi-SantosOlv/cotacao-dolar-python.git
   ```
3. Crie e ative o ambiente virtual:
   ```bash
   python -m venv venv
   # No Windows:
   venv\\Scripts\\activate
   # No Linux/Mac:
   source venv/bin/activate
   ```
4. Entre na pasta do projeto e execute:
   ```bash
   python main.py
   ```
